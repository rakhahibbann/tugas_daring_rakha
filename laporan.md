# Laporan Praktik BAB 6 - Pemrograman Server-Side

**Nama:** Rakha Hibban  
**Kelas:** XI RPL  
**Materi:** Menerapkan Pemrograman Server-Side

## 1. Tujuan
Memahami konsep server-side dan membuat aplikasi web dinamis menggunakan PHP serta database MySQL.

## 2. Teknologi
- HTML
- CSS
- PHP
- MySQL
- XAMPP

## 3. Hasil Praktik
Aplikasi memiliki halaman login dan dashboard. Setelah login berhasil, pengguna dapat menambahkan, melihat, dan menghapus data pengguna yang tersimpan di database.

## 4. Kesimpulan
Pemrograman server-side memungkinkan website memproses data di server. Dengan PHP dan MySQL, website dapat menjadi dinamis dan dapat menyimpan serta mengambil data dari database.
